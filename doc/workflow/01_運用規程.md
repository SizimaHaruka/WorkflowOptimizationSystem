# 合理化検討業務 運用規程

## 1. 目的
業務合理化およびシステム化検討について、案件受付から実施後評価までの責任、手順、成果物および判断基準を定める。

## 2. 適用範囲
- 業務工数、待ち時間、手戻り、転記等を削減する案件
- 紙、Excel、メール等を使用する業務の見直し
- 既存システム改修、連携、新規導入の検討
- 部署間の情報授受、承認、責任分担の見直し
- 標準化、属人化解消、内部統制強化

障害復旧、軽微な設定変更、単純な機器交換は、別の手順規定を適用とする。

## 3. 役割
|役割|責任|
|---|---|
|案件依頼者|背景、問題、期待成果を説明する|
|案件責任者|対象範囲、優先順位、実施判断、効果確認に責任を持つ|
|合理化担当者|調査、分析、改善案立案、成果物作成を主導する|
|業務担当者|現状、判断、例外、問題を説明し、As-Isを確認する|
|システム担当者|技術、既存資産、セキュリティ、保守を評価する|
|承認者|各ゲートの完了と次フェーズへの移行を判断する|

## 4. ステータス
```text
受付
→ 事前確認中
→ 調査中
→ As-Is確認中
→ 改善案検討中
→ 評価中
→ To-Be検討及び確認中
→ 実施判断待ち
→ 実施中
→ 効果確認中
→ 完了
```
保留、中止、差戻しを補助ステータスとして使用する。

## 5. ゲート
|ゲート|完了条件|
|---|---|
|G0 調査着手|問題、依頼者、責任者、概略範囲が明確|
|G1 範囲確定|開始点、終了点、対象部署、除外範囲が合意済み|
|G2 As-Is確定|通常、例外、判断、入出力、前後関係が確認済み|
|G3 改善案選定|複数案の効果、費用、リスクを比較済み|
|G4 To-Be確定|改善後の役割、作業、情報、例外、統制が合意済み|
|G5 実施判断|要求、予算、体制、移行、教育、評価方法が明確|
|G6 案件終結|効果実績、残課題、標準化状況を記録済み|

## 6. 記録管理
- 案件ごとに案件番号を付与する。
- 成果物は案件フォルダまたは案件管理システムへ保存する。
- 重要な判断、範囲変更、要求変更は意思決定記録（ADR）に残す。
- 空欄は「未確認」「該当なし」「不明」を区別する。
- 版番号、作成日、作成者、確認者を記録する。
