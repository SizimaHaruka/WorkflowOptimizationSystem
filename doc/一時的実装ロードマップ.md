# 一時的実装ロードマップ

作成日: 2026/07/20

本書は、現在の運用確認で見つかった改善を優先順位付きで進めるための一時的な作業メモである。恒久的な業務設計書ではなく、完了した項目は実装・テスト結果とともに本書から取り除く。

## 優先順位

|優先|作業|目的|完了条件|
|---|---|---|---|
|3|ゲート完了条件の精緻化|成果物間のつながりを承認条件に反映する|問題→改善案→To-Be→要求事項の紐付け・選定・受入条件を検証|
|4|基準版差分表示|再承認時の変更点を容易に確認する|前版との差分を項目単位で表示|
|5|権限設計|利用者に応じた操作範囲を定める|閲覧・編集・ゲート判断の権限をgauth利用者と対応付ける|
|6|運用ダッシュボード|日常運用で滞留を把握できるようにする|期限超過、判断待ち、差戻し案件を一覧で確認できる|

## 今回の着手範囲

優先3を実施する。G3〜G5では、問題・改善案・To-Be作業・要求事項の紐付けと状態をサーバー側で検証し、利用者がチェックボックスを操作するだけでは承認できないようにする。
