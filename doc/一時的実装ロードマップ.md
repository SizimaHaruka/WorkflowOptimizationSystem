# 一時的実装ロードマップ

作成日: 2026/07/20

本書は、現在の運用確認で見つかった改善を優先順位付きで進めるための一時的な作業メモである。恒久的な業務設計書ではなく、完了した項目は実装・テスト結果とともに本書から取り除く。

## 優先順位

|優先|作業|目的|完了条件|
|---|---|---|---|
|0|未マージ修正の統合・配備|編集画面と基準版表示の修正を利用可能にする|マージ、DBマイグレーション適用、実環境での確認|
|1|ゲート遷移の統制|承認履歴・案件状態・基準版の整合性を保つ|前提ゲートの最新判定を確認し、手動で工程状態を変更できない|
|2|基準版のE2E検証|承認後の状態と履歴を回帰させない|保存→承認→確認済み→再編集→下書き→履歴不変を自動検証|
|3|ゲート完了条件の精緻化|成果物間のつながりを承認条件に反映する|問題→改善案→To-Be→要求事項の紐付け・選定・受入条件を検証|
|4|基準版差分表示|再承認時の変更点を容易に確認する|前版との差分を項目単位で表示|
|5|権限設計|利用者に応じた操作範囲を定める|閲覧・編集・ゲート判断の権限をgauth利用者と対応付ける|
|6|運用ダッシュボード|日常運用で滞留を把握できるようにする|期限超過、判断待ち、差戻し案件を一覧で確認できる|

## 今回の着手範囲

優先1から開始する。案件の工程ステータスはゲートの承認・差戻しで遷移させ、案件詳細からの手動変更は例外状態（保留・中止）の記録に限定する。また、後続ゲートの承認では前提ゲートの**最新**判定が承認であることを確認する。
